# `exam`

This directory contains programs for examining the distribution of the number of shuffles required by the bogo-sort algorithm used in `luck.py`. For each seed, the program repeatedly shuffles six integers from `0` through `5` until they are sorted. It repeats this examination for many seeds and records percentile thresholds from 0.1% through 100.0% in 0.1% increments.

## Files

| File | Description |
| --- | --- |
| `luck_examine.cpp` | C++17 implementation. Examines 1,000,000 seeds and writes the percentile data and an SVG plot. |
| `luck_examine.py` | Python implementation. Examines 100,000 seeds, writes the percentile data, and displays a plot with Matplotlib. |
| `Makefile` | Defines targets for building and running the C++ implementation and running the Python implementation. |
| `exam_data.txt` | Percentile data generated by either implementation. |
| `exam_plot.svg` | SVG plot generated by the C++ implementation. The Python implementation displays a plot without updating this file. |

## Requirements

The C++ implementation requires a C++17 compiler and `make`. The Python implementation requires Python 3 and the packages listed in `setup/requirements-exam.txt` at the repository root.

To create a virtual environment and install the Python dependencies, run the following commands from the repository root:

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r setup/requirements-exam.txt
```

## Usage

### C++ implementation

Run the following command from the repository root. The `run` target builds `luck_examine` first when necessary.

```sh
make -C exam run
```

The command writes the following files to `exam/`:

```text
exam/exam_data.txt
exam/exam_plot.svg
```

### Python implementation

```sh
make -C exam python
```

The command updates `exam/exam_data.txt` and displays the plot in a Matplotlib window. The command does not finish until the plot window is closed.

### Remove the compiled executable

```sh
make -C exam clean
```

This command removes only `exam/luck_examine`. It leaves the data and SVG files in place.

## Output format

`exam_data.txt` is a 1,000-line text file with no header. Each line has the following format:

```text
<percentile> <number of attempts>
```

For example, `50.0% 500` means that at least 50.0% of the examined samples became sorted within 500 attempts, and that 500 is the smallest attempt count with that property for the recorded distribution.

The plot uses the number of attempts on the x-axis and the percentage of samples sorted within that number of attempts on the y-axis.

## Examination conditions and reproducibility

The examination conditions are fixed in `main()` in each source file. The current values are:

| Condition | C++ | Python |
| --- | ---: | ---: |
| Number of items | 6 | 6 |
| Number of seeds examined | 1,000,000 | 100,000 |
| Starting seed | 2026 | 2026 |
| Progress interval | 10,000 | 1,000 |

For examination index `i`, the program adds `i` multiplied by a random integer from 1 through 10 to the running seed. The random sequence used for these factors is initialized with `std::random_device` in C++ and `secrets` in Python. As a result, repeated runs can produce different output even when the starting seed is unchanged.

The C++ and Python implementations also use different random-number libraries, shuffle implementations, and examination sizes. They implement the same examination method, but their numeric outputs are not intended to match one-to-one as a reproducibility test.

The programs resolve output paths relative to the current working directory. Use `make -C exam ...`, or change to `exam/` before running a program, to keep the output files in `exam/`.
